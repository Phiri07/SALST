Select a tag to begin.

Arrow keys steer the selected virtual tag. On a phone, draw a route directly on the map and press Follow drawn path. One path per tag command; new commands replace the old one. This is a software demonstration, not real cattle control.

Map updates every 2 seconds. Draw with a finger or mouse. Switch to the monitoring PWA to reset emergency mode after the tag returns inside the boundary.
